# Thekua

Single-page HTML shop for **Ranju's Kitchen — Ghar Wali Thekuwa**, selling thekua and snack products.

## Files
- `index.html` — the shop page
- `*.jpg` — product and hero images (coconut, cookies, ghee, power bar, sugar-free, ingredients)

## Run
Open `index.html` in a browser. Keep the images in the same folder.
